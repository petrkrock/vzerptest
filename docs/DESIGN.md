# DESIGN — UI-конвенции ВСЕМЗАПЧАСТИ CRM (vzcrm)

> Единый язык интерфейса проекта. Источник истины: `src/index.css` (@layer components),
> `tailwind.config.ts` (токены бренда). Новый раздел/экран собирается ТОЛЬКО из этих
> примитивов — не вводить новые цвета акцента и ui-фреймворки.

## 1. Дизайн-токены

| Токен | Значение |
|---|---|
| Акцент (основной) | `brand-red` `#CC0000` (hover `brand-red-dark` `#AA0000`) |
| Текст | `brand-black` `#1A1A1A`, вторичный `gray-500/600`, слабый `gray-400` |
| Фон | белый; подложки `brand-gray` `#F5F5F5`, рамки `brand-gray-mid` `#E0E0E0` |
| Успех | `green-600` (подтверждение, «Выполнено») |
| Инфо | `blue-700` (вторичный акцент, «Завтра») |
| Предупреждение | `amber-100/amber-700` (статусы «Новое/Новый») |
| Шрифт | Inter, system-ui (16px / 1.5) |

## 2. Компонентные классы (`src/index.css`)

| Класс | Применение |
|---|---|
| `btn-primary` | Главное действие (чёрная кнопка). Варианты: `btn-danger` (красная, удаление/акцент), `btn-activate` (зелёная), `btn-secondary` (контурная) |
| `form-input` / `form-label` | Все поля ввода и подписи |
| `card-base` | Любой контейнер-блок: фильтры, таблицы, формы, сводки |
| `page-title` / `section-title` | Заголовок страницы / блока |
| `table-header` / `table-cell` / `table-row` | Таблицы (плотные, `table-cell` py-0.3rem по ТЗ v1.23.52) |
| `status-badge` | Цветной бейдж статуса (rounded-full) |
| `stat-card` | KPI-карточки дашбордов |
| `tab-button` + `tab-active`/`tab-inactive` | Вкладки внутри разделов |
| `sidebar-link` + `-active`/`-inactive`, `bottom-nav-link` | Навигация (рендерится из navConfig) |
| `animate-fade-in` | Появление модалок/подсказок |

## 3. Паттерны разделов

- **Шапка раздела**: `page-title` + действия справа (`flex items-center justify-between gap-2 flex-wrap`).
- **Фильтры**: `card-base p-3` — поиск (`flex-1 min-w-[180px]`), селекты `w-auto`,
  чипы-статусы rounded-full (активный — `bg-red-600 text-white`).
- **Таблица**: `card-base overflow-hidden` → `overflow-x-auto` → thead `table-header`
  (uppercase, серый) → строки `border-t border-gray-100 hover:bg-gray-50`,
  кликабельные действия-иконки (Pencil/Trash2/History, `text-gray-400 hover:*`).
- **Сводки/KPI**: `stat-card`, крупные числа `text-2xl/3xl font-bold tabular-nums`.
- **Модалки**: `card-base w-full max-w-lg p-6 animate-fade-in` (стандарт проекта).
- **Чипы-поставщики/города**: `text-[11px] px-3 py-1.5 rounded-full border`,
  выбранный — красный фон; статусные цвета: красный = проблема/нет данных,
  зелёный = готово.
- **Пустые состояния**: «—» в ячейках, центрированный `text-gray-400` в теле таблицы.
- **Даты**: хранение ISO `YYYY-MM-DD`, показ `дд.мм.гггг`
  (`String(date).split('-').reverse().join('.')`).
- **Деньги**: `tabular-nums`, формат `N ₽`; перерасчёты — «N + M ₽».
- **Уведомления**: только `sonner` (`toast.success/error`) — без alert/confirm
  (кроме печати маршрутов).
- **Чекбоксы**: `accent-red-600` (фирменный акцент).
- **Иконки**: только `lucide-react`, размер 14–18px в строках таблиц.

## 4. Адаптив (мобильный)

- Тач-цели ≥ 40px (кнопки/поля), на мобильном поля `font-size: 16px` (iOS не зумит).
- ≤640px: `page-title`/`section-title` даунскейлятся, таблицы компактнее +
  горизонтальный скролл (`table-scroll`), строка поиска в фильтрах — на всю ширину.
- Навигация: BottomNav (3 приоритетных таба + «Ещё») вместо Sidebar.
- Верстка: мобильная адаптация — только стили/масштабы, логика и разметка
  не затрагиваются (политика ТЗ v1.22.4).

## 5. Анти-паттерны (запрещено)

1. Новые акцентные цвета вне палитры и новые ui-библиотеки.
2. Inline-стили, кроме печатных форм (`window.open` + HTML для печати маршрутов).
3. alert/confirm/prompt нативные — только кастомные модалки и sonner.
4. Физическое удаление данных — только мягкое (`deletedAt`) + журнал.
5. Логика в CSS-медиазапросах (только визуал).
6. «Глазами» — каждая правка прогоняется компилятором перед отдачей (WORKFLOW.md).
